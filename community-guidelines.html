إرشادات المجتمع

تاريخ السريان: 18 أغسطس 2026

صُممت AdenTweet للمحادثات العامة البنّاءة. تنطبق هذه الإرشادات على المنشورات والوسائط والرسائل والمجتمعات والملفات الشخصية ورسائل صراحني المجهولة.

السلامة والاحترام

يُمنع التهديد أو التحرش أو المطاردة أو التنمر أو التشهير أو كشف المعلومات الشخصية أو انتحال الهوية أو التشجيع على العنف. كما يُمنع خطاب الكراهية أو تمجيد الجماعات المتطرفة أو استهداف الأشخاص أو المجموعات بسبب صفات محمية.

حماية القاصرين والأشخاص المعرّضين للخطر

يُحظر الاستغلال أو الاستدراج أو أي محتوى جنسي يخص قاصرين، ويجوز إبلاغ الجهات المختصة عند اللزوم. لا تستخدم الخدمة لتسهيل إيذاء النفس أو تحديات خطرة أو عنف.

الأصالة والأمان

لا تستخدم البريد المزعج أو السلوك المنسق غير الأصيل أو التصيد أو الاحتيال أو البرمجيات الخبيثة أو الروابط الخادعة أو شراء وبيع الحسابات أو الأدوات التي تتجاوز الضوابط. لا تتحايل على عمليات الحظر أو الإيقاف.

صراحني

صراحني مخصصة للملاحظات المحترمة المجهولة، وليست للتحرش. لا يرى المستلم هوية المرسل، لكن المنصة قد تحتفظ بسجل محدود لمكافحة الإساءة وتطبيق حدود الإرسال. الرسائل المتكررة غير المرغوبة أو التهديدية أو الكارهة أو الجنسية أو الخادعة قد تؤدي إلى إنفاذ ضد الحساب المرسل.

الإبلاغ والإنفاذ

يمكنك الإبلاغ عن المحتوى من داخل التطبيق. حسب الخطورة والسياق، قد نزيل المحتوى أو نخفض توزيعه أو نعطل ميزات أو نسحب شارة أو نعلق الحساب أو ننهيه، وقد نحتفظ بالمادة أو نفصح عنها عندما يفرض القانون ذلك. تُمنح أولوية للمخاطر الوشيكة والقاصرين والمحتوى الحميمي غير الرضائي والاحتيال والسلوك غير القانوني.
